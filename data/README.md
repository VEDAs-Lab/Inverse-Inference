# Data Directory

This directory holds dataset metadata and (locally generated) intermediate
files. Raw images and large CSVs are **not committed to git** — see
`dataset_links.txt` for download sources.

## Expected files

| File | Source | Description |
|------|--------|-------------|
| `slimia_metadata.csv` | SLiMIA dataset (download) | Master metadata CSV — one row per image, with `full_path`, `mask_path`, and all 9 protocol attributes |
| `shape_features_with_metadata.csv` | Generated by `03_morphometry_extraction.ipynb` | 9 morphometric descriptors merged with metadata — required by `ImageShapeFusionTransformer` |

## `slimia_metadata.csv` schema

Required columns:

- `full_path` — absolute path to the `.ome.tiff` image
- `mask_path` — absolute path to the manual segmentation mask (ground truth, used only for segmentation training)
- `microscope`, `cell_line`, `culture_medium`, `formation_method`,
  `seeding_density`, `timepoint`, `biological_rep`, `technical_rep`, `magnification`
- `timepoint_hour` — numeric hour extracted from `timepoint` (e.g. `024h` → `24`)
- `seeding_density_num` — numeric seeding density (e.g. `2000cells` → `2000`)

## Building the metadata CSV

If you only have a folder of `.ome.tiff` files + a separate metadata table from
the SLiMIA download, run the helper script (or notebook cell) that:

1. Walks the image directory
2. Joins on filename with the official SLiMIA metadata table
3. Parses `timepoint` → `timepoint_hour` and `seeding_density` → `seeding_density_num`
4. Writes `slimia_metadata.csv` with the schema above

See `01_dataset_analysis.ipynb` for the parsing logic (`parse_hour`, `extract_numeric_seeding`).
